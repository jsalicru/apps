# E36 Cluster Test

Experimental standalone app for testing the E36 cluster before enabling it in P3 Clusters.

**Safety:** This app and P3 Clusters both target the same cluster-render panel. Stop/disable P3 Clusters before enabling this test app. Do not run both concurrently.

The default layout is **Off**; change it to E36 only when ready to test. Restore Off before switching back to P3 Clusters.

This is a test app, not a guaranteed sandbox: selecting E36 draws to the actual cluster. Test in a bench/emulator first.
