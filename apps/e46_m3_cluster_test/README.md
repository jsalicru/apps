# E46 M3 Cluster Test — scaffold only

This is a **non-rendering development scaffold**, not a working E46 beta. The only selectable layout is **Off** (BMW original cluster). Do not install expecting E46 graphics.

Target: 2022 BMW M3 G80, S58, iDrive 7. The standalone app has its own ID and settings and shares the proven app infrastructure. The E46 renderer, layouts and temperature signal integration are still pending. Never run it alongside P3 Clusters or E36 Cluster Test.

See `docs/e46-m3-beta-checklist.md` for release gates.
